# AVETRA v1.5

Input nama (1–9 komponen A–Z) dan tanggal lahir untuk menghasilkan 100 Vitranta otomatis, Synergy, Productive, Momentum dan Life Map. Algoritma dibangun dari bytecode `SCSClass.class`. Tanggal lahir dipakai sebagai label tahun, tidak sebagai pembangkit pola angka Vitranta dalam kode aslinya. Mode audit manual tetap tersedia.

Unggah semua file dari ZIP ke root GitHub Pages. Refresh Safari setelah deployment.
